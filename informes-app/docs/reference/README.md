# Material de referencia (spec sección 15)

Archivos adjuntos originales del cliente — fuente de verdad de diseño/UX.
No se usan en runtime, son solo referencia para desarrollo:

- `informe-tecnico-wireframe.html`: prototipo navegable. Ante cualquier duda
  de comportamiento, abrirlo en el navegador y probarlo antes de asumir.
- `Informe Tecnico - Diseno PDF.pdf` / `.docx`: diseño aprobado del PDF de
  Informe Técnico — replicado en `src/lib/pdf/informe-tecnico.tsx`.
- `Rendicion de Gastos - Diseno PDF.pdf` / `.docx`: diseño aprobado del PDF
  de Rendición de Gastos — todavía no implementado (ver README principal).
