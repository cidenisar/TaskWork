desconectado
El usuario MQTT es el id de la consola elegida arriba — Mosquitto ahora exige credenciales (dynamic-security) y solo deja publicar en el tópico de la propia consola. Para simular otra consola, recargá la página.
Si se completa, el backend liga el evento a esa fila: la marca realizado, genera la próxima ocurrencia si es recurrente, y usa su escenario/tipo para el despacho y para evento-activo (activa el relé si el tipo lo tiene configurado). Así se prueba el flujo completo de un simulacro programado disparándose de verdad, no solo un evento suelto.
